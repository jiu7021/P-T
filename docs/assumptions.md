# 가정과 근거

이 문서는 **합성·추정에 들어간 모든 가정**을 한곳에 모은다.
각 항목은 반드시 다음을 갖는다: 가정 내용 / 근거 유형 / 결론에 미치는 영향 / 민감도 확인 결과.

근거 유형 표기 규칙 (전역 규칙과 동일):
`(물성치)` `(통상범위)` `(표준·규정)` `(가정치)`

---

## 상태

| 절 | 내용 | 상태 |
|---|---|---|
| A-1 | 웨이퍼 샘플링 기준(다이 수 600~1500, 균형 샘플링 2,000장) | 미작성 |
| A-2 | 순차 테스트 순서 정의 | 미작성 |
| C-1 | 테스트 항목의 상대 시간·검출 확률 | 미작성 |
| C-2 | 불량 모드 할당 규칙, 파라메트릭 마진의 공간 구조 | 미작성 |
| C-4 | 상대 원가 식의 계수, 스택 단수 계수 | 미작성 |
| C-5 | 민감도 분석 결과 | 미작성 |

각 Module 진행 시 해당 절을 채운다. **빈 상태로 다음 Module에 넘어가지 않는다.**
