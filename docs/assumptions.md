# 가정과 근거

이 문서는 **합성·추정에 들어간 모든 가정**을 한곳에 모은다.
각 항목은 반드시 다음을 갖는다: 가정 내용 / 근거 유형 / 결론에 미치는 영향 / 민감도 확인 결과.

근거 유형 표기 규칙 (전역 규칙과 동일):
`(물성치)` `(통상범위)` `(표준·규정)` `(가정치)`

## A-1. 웨이퍼 선별과 샘플링

### A-1-a. 다이 수 600~1500으로 제한

- 근거 유형: **(가정치)** — 프로젝트 사양으로 주어진 값이다.
- 의도: 웨이퍼당 다이 수가 3~48,099로 3자릿수 이상 차이 나므로, 공간 특징과
  테스트 시간 비교를 같은 스케일에서 하기 위해 중간 대역만 남긴다.
  (원본 중앙값 953은 이 구간 안에 있다.)
- 결론에 미치는 영향: 대면적 다이(고가·저다이수) 제품은 표본에 없다.
  Module C의 상대 원가 결론을 대면적 제품에 그대로 적용할 수 없다.
- 민감도: 미확인. 구간을 넓히면 웨이퍼당 다이 수 분산이 커져 시간 지표의
  분산이 커질 것으로 예상되나 검증하지 않았다.

### A-1-b. 패턴 클래스 균형 샘플링 (실제 분포가 아님)

- 근거 유형: **(가정치)** — 프로젝트 사양.
- 실제 분포는 `none` 85.25%로 극단적으로 치우쳐 있다. 균형 샘플링은 희귀 패턴의
  공간 구조를 학습·관찰하기 위한 선택이다.
- **결론에 미치는 영향(중요)**: 표본 전체 불량률 23.04%는 실제 라인 수율이 아니다.
  Module C의 Escape DPPM·Overkill 절대값도 이 표본 분포에 종속된다.
  **절대값이 아니라 정책 간 상대 비교에만 쓴다.**
- 민감도: Module C-5에서 불량 모드 분포 시나리오를 바꿔 확인한다.

### A-1-c. Near-full은 83장뿐이므로 균등 할당을 포기했다

- 근거 유형: **(실측)** — 필터 후 가용량이 83장.
- 영향: Near-full 클래스의 통계는 다른 클래스보다 표본 수가 1/3 미만이다.
  클래스별 지표를 볼 때 표본 수를 항상 병기한다.

## A-2. 순차 테스트 순서

### A-2-a. 스캔 순서를 serpentine으로 정의

- 근거 유형: **(통상범위)** — 프로버 스텝 이동 거리 최소화. 행 끝에서 되돌아가는
  단방향 래스터보다 이동이 짧다. 실제 장비의 스캔 경로는 제품·장비마다 다르며,
  본 데이터에는 스캔 순서 정보가 없다.
- 대안(단방향 래스터)을 쓰지 않은 이유: 모든 행에서 "이미 테스트된 이웃"이 항상
  왼쪽에만 생겨 좌우 비대칭 편향이 특징에 들어간다.
- 결론에 미치는 영향: 이웃 특징의 값 자체는 순서 정의에 종속된다. 다만 **공간
  상관의 존재 여부**(표 A-2)는 순서 정의와 무관하게 성립한다.
- 민감도: 미확인. 순서를 바꾸면 `nb8_tested_cnt` 분포가 달라지므로 예측 모델의
  성능이 다소 변할 수 있다. Module C-5의 민감도 항목에 포함할지 검토한다.

### A-2-b. 반경 2 이웃에도 '이미 테스트된' 조건을 적용

- 근거 유형: **(설계 원칙)** — 프로젝트 절대 원칙의 미래 정보 누수 금지.
- 프로젝트 명세에는 8-이웃에만 이 조건이 붙어 있었으나, 반경 2에만 미래 정보를
  허용하면 그 경로로 누수가 들어온다. 명세보다 엄격한 쪽으로 처리했다.
- 결론에 미치는 영향: 성능 수치가 낮아지는 방향이다. 유리한 쪽 선택이 아니다.

## EDS. 웨이퍼 테스트 시뮬레이터

웨이퍼 테스트는 프로브로 전압을 인가해 출력이 규격에 맞는지 보는 **전기 시험**이다.
결함 이미지 분석은 이 단계에서 하지 않는다(FA 단계다).

### 실데이터와 합성의 경계

| 무엇 | 출처 |
|---|---|
| 어느 좌표의 다이가 불량인가 | **WM-811K 실데이터** |
| 불량이 웨이퍼 위에 어떻게 분포하는가 | **WM-811K 실데이터** |
| 그 다이가 어느 시험에서 어떤 값으로 걸렸는가 | **합성** |
| fail bit이 칩 안 어느 주소에 있는가 | **합성** |
| 정상 다이의 파라메트릭 여유값 | **합성** (공간 상관 구조는 실데이터 분포를 따름) |

코드에서 이 경계는 `synth_measurements()`(값 생성)와 `inject_defects()`(실데이터가
불량이라 정한 다이에만 불량 부여)로 분리돼 있다.

### EDS-a. 시험 온도 25 °C / 85 °C

- 근거 유형: **(통상범위)** — 상온·고온 시험 온도로 통상 쓰이는 대역.
- 온도가 오르면 접합 누설이 커져 셀 보유 시간이 짧아진다. 상온에서 통과하던 셀이
  고온에서 떨어지는 일이 이 때문에 생긴다.
- 출처: A. Bouhdada, J. Oualid, "MOS capacitor holding time and diffusion length at
  DRAM refresh test temperature," *Microelectronics Journal*, vol. 26, no. 5,
  pp. 405-412, 1995. doi:10.1016/0026-2692(95)98942-k
- 서지는 Crossref로 대조했으나 본문을 읽어 검증하지는 않았다. 제목에서 확실한
  범위("리프레시 시험 온도에서 커패시터 보유 시간이 온도에 의존한다")까지만 쓴다.

### EDS-b. 시험 규격값

| 항목 | 규격 | 근거 유형 |
|---|---|---|
| 핀 전압(오픈/쇼트) | -1.20 ~ -0.40 V | **(가정치)** 보호 다이오드 강하 대역을 상정 |
| 대기 전류 | ≤ 3.0 mA | **(가정치)** |
| 동작 전류 | ≤ 120 mA | **(가정치)** |
| 리텐션 보유 시간 | ≥ 64 ms | **(통상범위)** 리프레시 주기 64 ms 급을 기준 |

**절대값이 실제 제품과 같다고 주장하지 않는다.** 항목 간 상대 관계(고온 리텐션이
상온보다 짧다, 오픈이면 전압이 크게 음이 된다)만 물리적으로 타당하게 잡았다.

### EDS-c. 여분 행 4 / 여분 열 4

- 근거 유형: **(가정치)** — 실제 제품의 여분 개수는 공개되어 있지 않다.
  리페어 분석 알고리즘 문헌이 다루는 대표 구성을 따랐다.
- 출처: H. Kwon, J. Moon, J. Byun et al., "Linear search algorithm for repair analysis
  with 4 spare row/4 spare column," *IEEE APASIC*, pp. 269-272, 2000.
  doi:10.1109/apasic.2000.896960
- **결론에 미치는 영향(큼)**: 여분 개수가 Repairable 비율을 직접 결정한다.
  민감도를 반드시 함께 본다.

### EDS-d. 불량 다이 중 25%는 리페어 불가한 칩 전체 특성 불량

- 근거 유형: **(가정치)** — 근거가 되는 공개 통계가 없다.
- 논리적 근거는 있다: 여분 행·열은 **셀 어레이**를 대체하는 자원이다. 전류가 규격을
  넘거나 배선이 끊긴 것은 대체할 대상이 없어 리페어가 성립하지 않는다.
  비율 25%라는 **숫자 자체**가 가정이다.
- **결론에 미치는 영향(큼)**: 이 비율이 Fail 하한을 정한다. 민감도 필수.

### EDS-e. 웨이퍼 패턴별 셀 어레이 불량 모드 배분

`MODE_MIX` — **전부 가정치.** 물리적으로 그럴듯한 방향만 반영했다.

| 패턴 | 싱글비트 | 로우성 | 칼럼성 | 블락성 | 크로스 | 방향의 근거 |
|---|---:|---:|---:|---:|---:|---|
| Random | .85 | .05 | .05 | .04 | .01 | 산발 불량이므로 고립 셀 위주 |
| Scratch | .20 | .35 | .30 | .10 | .05 | 선상 손상이 라인 방향 불량을 만든다 |
| Loc / Center | .25 | .10 | .10 | .50 | .05 | 국소 밀집이 블록 단위 불량으로 나타난다 |
| Donut | .25 | .12 | .12 | .46 | .05 | 위와 같음 |
| Edge-Loc / Edge-Ring | .30 | .12~.15 | .12~.15 | .35~.41 | .05 | 위와 같음 |
| Near-full | .20 | .15 | .15 | .40 | .10 | 대부분 불량이므로 규모가 큰 모드 비중 증가 |
| none | .70 | .10 | .10 | .08 | .02 | 뚜렷한 패턴이 없으므로 고립 셀 위주 |

- **결론에 미치는 영향(큼)**: 모드가 Repairable 여부를 좌우한다. 로우성 1줄은
  여분 행 1개로 끝나지만, 블락성은 행·열을 여러 개 잡아먹는다.
- 민감도 필수.

### EDS-f. fail bit 개수 범위

| 모드 | fail bit 수 | 근거 유형 |
|---|---|---|
| 싱글비트 | 1 ~ 6 | **(가정치)** |
| 로우성 / 칼럼성 | 8 ~ 60 | **(가정치)** 한 라인에 걸친 규모 |
| 블락성 | 10 ~ 120 | **(가정치)** |
| 크로스 | 20 ~ 150 | **(가정치)** 행·열이 겹쳐 규모가 가장 크다 |

### EDS-g. 상온/고온 fail bit 비, 리텐션 불량 확률

- 상온 fail bit 수 = 고온의 55~100% — **(가정치)**. 고온에서 더 많이 드러난다는
  방향만 반영했다.
- 셀 어레이 불량 다이의 35%가 리텐션 규격 미달 — **(가정치)**.

### 민감도를 반드시 봐야 할 항목

1. 여분 행·열 개수 (EDS-c)
2. 리페어 불가 비율 (EDS-d)
3. 불량 모드 배분 (EDS-e)

이 셋이 Good/Repairable/Fail 비율을 직접 정한다. 값을 바꿔가며 결론이 얼마나
흔들리는지 보고한다. 흔들리면 그것도 결과다.
