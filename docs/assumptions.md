이 문서는 **합성·추정에 들어간 모든 가정**을 한곳에 모은다.
각 항목은 반드시 다음을 갖는다: 가정 내용 / 근거 유형 / 결론에 미치는 영향 / 민감도 확인 결과.

근거 유형 표기 규칙 (전역 규칙과 동일):
`(물성치)` `(통상범위)` `(표준·규정)` `(가정치)`

## A-1. 웨이퍼 선별과 샘플링

### A-1-a. 다이 수 600~1500으로 제한

- 근거 유형: **(가정치)** — 프로젝트 사양으로 주어진 값이다.
- 의도: 웨이퍼당 다이 수가 3~48,099로 3자릿수 이상 차이 나므로, 공간 특징과
  테스트 시간 비교를 같은 스케일에서 하기 위해 중간 대역만 남긴다.
  (원본 중앙값 953은 이 구간 안에 있다.)
- 결론에 미치는 영향: 대면적 다이(고가·저다이수) 제품은 표본에 없다.
  Module C의 상대 원가 결론을 대면적 제품에 그대로 적용할 수 없다.
- 민감도: 미확인. 구간을 넓히면 웨이퍼당 다이 수 분산이 커져 시간 지표의
  분산이 커질 것으로 예상되나 검증하지 않았다.

### A-1-b. 패턴 클래스 균형 샘플링 (실제 분포가 아님)

- 근거 유형: **(가정치)** — 프로젝트 사양.
- 실제 분포는 `none` 85.25%로 극단적으로 치우쳐 있다. 균형 샘플링은 희귀 패턴의
  공간 구조를 학습·관찰하기 위한 선택이다.
- **결론에 미치는 영향(중요)**: 표본 전체 불량률 23.04%는 실제 라인 수율이 아니다.
  Module C의 Escape DPPM·Overkill 절대값도 이 표본 분포에 종속된다.
  **절대값이 아니라 정책 간 상대 비교에만 쓴다.**
- 민감도: Module C-5에서 불량 모드 분포 시나리오를 바꿔 확인한다.

### A-1-c. Near-full은 83장뿐이므로 균등 할당을 포기했다

- 근거 유형: **(실측)** — 필터 후 가용량이 83장.
- 영향: Near-full 클래스의 통계는 다른 클래스보다 표본 수가 1/3 미만이다.
  클래스별 지표를 볼 때 표본 수를 항상 병기한다.
