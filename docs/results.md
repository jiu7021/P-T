### 이 표를 읽을 때 반드시 함께 읽어야 할 것

1. **`none`은 "불량이 없다"가 아니라 "식별된 공간 패턴이 없다"는 뜻이다.**
   불량률 8.54%로 결코 0이 아니다. 산발 불량은 존재하되 패턴을 이루지 않는 상태다.
2. **전체 불량률 23.04%는 실제 라인의 수율이 아니다.** 균형 샘플링 때문에 희귀
   패턴(Near-full 87%, Random 48%)이 실제 비율보다 크게 과대표집되었다.
   원본 라벨 보유분에서 `none`이 85.25%임을 감안하면, 실제 라인 평균 불량률은
   이보다 훨씬 낮다. **이 수치를 수율로 인용하지 않는다.**
3. 다이 수를 600~1500으로 제한했으므로 대면적/소면적 제품은 표본에서 빠져 있다.

### 직전 웨이퍼 확보 (A-2 특징 전용)

균형 샘플링을 하면 같은 로트의 연속 웨이퍼가 함께 뽑힐 확률이 낮다. 따라서
"같은 로트 직전 웨이퍼의 동일 좌표 불량" 특징을 위해 직전 웨이퍼
(`lot_id` 동일, `wafer_index - 1`)를 **원본 전체에서 따로 조회**해 저장했다.

| 항목 | 값 |
|---|---:|
| 직전 웨이퍼를 찾은 웨이퍼 | 1,832 / 2,000 (91.6%) |
| 그중 맵 크기가 같아 좌표 대조 가능 | 1,832 (100%) |
| 결측 | 168 (8.4%) — 로트의 첫 웨이퍼이거나 직전 인덱스가 원본에 없음 |

직전 웨이퍼는 라벨·다이 수 필터를 적용하지 않았다. 특징 계산에만 쓰고
**분석 표본에는 포함하지 않는다.**

## Module A-2. 공간 특징 추출 — **WM-811K 실데이터**

실행: `.venv/bin/python src/features/spatial.py` (2,128,718행, 약 25초)

### 스캔 순서 정의 (미래 정보 누수 방지의 기준점)

**serpentine(뱀 모양)**: 행 0은 왼→오른쪽, 행 1은 오른→왼쪽, 이하 반복.

- 근거 **(통상범위)**: 프로버는 행 끝에서 시작점으로 되돌아가지 않고 방향을 바꿔
  진행하는 편이 스텝 이동 거리가 짧다.
- 단방향 래스터로 정의하면 모든 행에서 "이미 테스트된 이웃"이 항상 왼쪽에만
  생겨 좌우 비대칭 편향이 특징에 들어간다. serpentine은 행마다 방향이 바뀌어
  이 편향이 상쇄된다.

### 추출한 특징 (다이당 12개)

| 특징 | 정의 | 미래 정보 여부 |
|---|---|---|
| `r_norm` | 유효 다이 무게중심 기준 거리 / 최대 거리 | 기하학적, 무관 |
| `edge_dist`, `edge_dist_norm` | 유효 영역 거리 변환(EDT) 값 | 기하학적, 무관 |
| `nb8_tested_cnt` | 8-이웃 중 **이미 테스트된** 다이 수 | 과거만 |
| `nb8_tested_fail_rate` | 위 이웃들의 불량 비율 | 과거만 |
| `nb_r2_tested_cnt` | 유클리드 반경 2 이내 이웃 중 이미 테스트된 수 | 과거만 |
| `nb_r2_tested_fail_rate` | 위 이웃들의 불량 비율 | 과거만 |
| `prev_wafer_fail` | 같은 로트 직전 웨이퍼 동일 좌표 불량 여부 | 이전 웨이퍼, 무관 |
| `scan_rank`, `scan_progress` | 웨이퍼 내 테스트 순번 / 진행률 | 자기 순번, 무관 |

명세의 "반경 2 이내 이웃 불량 비율"에는 원래 '이미 테스트된' 조건이 붙어 있지
않았으나, **8-이웃과 동일하게 과거 다이만 쓰도록 제한했다.** 반경 2에만 미래
정보를 허용하면 그 경로로 누수가 들어온다.

### 누수 검증 결과 — 주장이 아니라 대조 결과

벡터화 코드가 조건을 지키는지 눈으로는 확인할 수 없으므로, 무작위 웨이퍼 20장 ×
다이 300개에 대해 이중 루프로 이웃을 다시 세어 대조했다(`verify_no_leakage`).

| 검증 | 결과 |
|---|---|
| 브루트포스 재계산 대조 | 12,000건 확인, **불일치 0건** |
| `scan_rank = 0` 다이의 이웃 수 | 2,000개 전부 0 (첫 다이는 이웃 정보가 있을 수 없음) |

검증에 실패하면 파일을 저장하지 않고 종료한다.

### **수용 기준 판정: 공간 상관은 실재한다**

- 이웃이 전부 정상일 때 9.01% → 불량 이웃 4개 이상일 때 87.12%. **9.7배 차이.**
- 로트 내 웨이퍼 간에도 상관이 있다. 직전 웨이퍼 동일 좌표가 불량이면
  17.97% → 45.57%. **2.5배.**
- **Module C(적응형 스킵)의 전제가 성립한다.** 앞서 테스트한 다이의 결과로
  다음 다이의 불량 확률을 예측할 근거가 데이터에 실제로 있다.

### 패턴 클래스별 상관 강도 — 정책 효과가 균일하지 않을 것을 예고한다

불량 이웃 0개일 때 대비 4개 이상일 때의 불량률 배수:

| 클래스 | 이웃 0개 | 이웃 4개+ | 배수 |
|---|---:|---:|---:|
| Loc | 8.31% | 88.64% | 10.7x |
| Center | 8.87% | 92.60% | 10.4x |
| Edge-Loc | 9.13% | 89.86% | 9.8x |
| Donut | 10.31% | 87.21% | 8.5x |
| Scratch | 6.88% | 50.74% | 7.4x |
| none | 6.64% | 46.15% | 7.0x |
| Edge-Ring | 8.68% | 55.54% | 6.4x |
| **Near-full** | 34.98% | 94.68% | **2.7x** |

Random과 Near-full의 상관이 약한 것은 물리적으로 타당하다. Random은 정의상 산발
불량이고, Near-full은 대부분이 불량이라 이웃 정보의 판별력이 낮다.
→ **적응형 스킵의 이득은 패턴에 따라 크게 다를 것이다.** Module C에서 패턴별로
   나누어 보고한다.
