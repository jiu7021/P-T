## 이 프로젝트로 무엇을 하려 했나

반도체 후공정(P&T)에서 **웨이퍼 테스트 결과를 보고 판단을 내리는 과정**을 화면 하나로
재현했다. 목적은 모델 정확도를 자랑하는 것이 아니라 다음 세 가지다.

1. **판단의 근거를 화면에 드러낸다.** 어떤 다이가 왜 Fail인지, 어떤 결함이 왜 그 원인
   공정으로 의심되는지를 수치와 문헌으로 보여준다. 결과만 던지지 않는다.
2. **실데이터와 합성의 경계를 표시한다.** 공개 데이터가 없는 부분은 합성했고, 그 사실을
   화면 상단에 계속 띄운다.
3. **AI가 판정하지 않는 선을 긋는다.** 원인 공정 추정은 문헌 룩업이며 확정은 사람이 한다.

## 화면 조작

### 1번 탭 — 웨이퍼 맵 분석

| 조작 | 결과 |
|---|---|
| 왼쪽 목록에서 웨이퍼 선택 | 가운데에 웨이퍼 맵과 판단 근거 히트맵이 뜬다 |
| 목록의 `✗` 표시 | 모델이 패턴을 틀린 웨이퍼. 잘 맞은 것만 고르지 않았다 |
| 오른쪽 "근거 영역(Grad-CAM)이 무엇인가" 펼치기 | 히트맵 설명 |

### 2번 탭 — EDS 웨이퍼 테스트 (핵심)

| 조작 | 결과 |
|---|---|
| 왼쪽 목록에서 웨이퍼 선택 | 다이별 등급 맵(초록/노랑/빨강) |
| **웨이퍼 맵의 다이를 클릭** | 그 다이의 시험 4종 측정값, 규격, 통과 여부, 판정 근거가 오른쪽에 뜬다 |
| 아래로 스크롤 | 시험 항목 6종 설명, 판정 논리, 모드별 리페어 성공률, 민감도 |

빨간 다이를 클릭하면 "리텐션 20.6 ms(규격 ≥64 미달), 블락성 fail bit 93개, 여분 행
4/4를 다 써도 남음 → Fail"처럼 **왜 그 등급인지**가 문장으로 나온다.

### 3번 탭 — Fail Address 분석

| 조작 | 결과 |
|---|---|
| 불량 모드 선택 + "다시 생성" | 그 모드에 맞는 fail 주소를 합성해 16진수 표와 산점도로 보여준다 |
| fail 개수 / 잡음 / 주소 간격 슬라이더 | 조건을 바꿔 재생성 |
| **판별 임계값 슬라이더 4개** | 판별 결과가 실시간으로 바뀐다. 임계값이 가정치라는 것을 직접 확인하는 장치다 |

예: 로우성 표본(최다 X가 전체의 90.9%)에서 `line_min_ratio`를 0.92로 올리면
판별이 싱글비트로 뒤집힌다.

### 4번 탭 — FA(SEM 결함 분석)

| 조작 | 결과 |
|---|---|
| 이미지 선택 | 큰 화면에 결함 위치 표시 |
| 표시 드롭다운 | 모델이 지목한 위치(빨강) / 전문가 정답(초록) / 둘 다 / 원본만 |
| 대비 강조 체크 | 원본 SEM은 대비가 낮아 그대로는 결함이 안 보인다. 표시용 처리 |
| 윤곽선만 체크 | 채우지 않고 테두리만 그려 원본을 가리지 않는다 |

### 5번 탭 — 판정 피드백 / 6번 탭 — 한계와 근거

조회 전용. 5번은 엔지니어 판정을 쌓는 구조와 학습 시작 기준, 6번은 데이터 한계와
성능 수치(기본 접힘)를 담았다.

## 용어 사전

### 테스트 단계

| 용어 | 뜻 |
|---|---|
| **EDS (웨이퍼 테스트)** | Electrical Die Sorting. 프로브 카드를 다이에 대고 **전압을 인가해** 출력이 규격에 맞는지 보는 전기 시험. 고온 조건도 여기서 건다. **이미지는 보지 않는다.** |
| **FA (불량 분석)** | Failure Analysis. 테스트에서 걸러진 다이를 뜯어 SEM 등으로 결함을 눈으로 확인하고 원인을 찾는 단계 |
| **프로브 카드** | 다이의 패드에 바늘을 대어 전기 신호를 주고받는 검사 도구 |

### 다이 등급

| 용어 | 뜻 |
|---|---|
| **다이(die)** | 웨이퍼 위의 칩 한 개. 웨이퍼 맵의 점 하나 |
| **Good** | 모든 시험을 규격 안에서 통과 |
| **Repairable** | 불량 셀이 있으나 **여분 행·열로 갈아끼워** 살릴 수 있음 |
| **Fail** | 여분이 모자라거나, 갈아끼울 수 없는 칩 전체 특성 불량 |
| **리페어 / 여분 행·열** | 메모리 칩에 미리 넣어둔 예비 행·열. 불량 셀이 나오면 퓨즈를 끊어 주소를 예비 쪽으로 돌린다 |
| **must-repair** | 어떤 행의 fail 수가 남은 여분 **열**보다 많으면 열로는 못 덮는다 → 그 행은 반드시 행 리페어를 써야 한다. 선택의 여지가 없는 배정 |

### 시험 항목

| 용어 | 뜻 |
|---|---|
| **오픈/쇼트** | 배선이 끊겼는지(오픈) 붙었는지(쇼트). 작은 전류를 넣고 전압을 재서 판단 |
| **대기 전류 / 동작 전류** | 아무 동작 없을 때 / 읽고 쓸 때 흐르는 전류. 누설이 있으면 커진다 |
| **기능 시험** | 정해진 패턴을 쓰고 다시 읽어 같은 값이 나오는지 확인 |
| **리텐션** | 값을 쓰고 리프레시를 멈춘 뒤 얼마나 오래 기억하는지. 고온일수록 빨리 샌다 |
| **리프레시** | DRAM이 전하를 잃기 전에 주기적으로 값을 다시 써넣는 동작 |

### Fail Address 불량 모드

| 용어 | 뜻 | 리페어 |
|---|---|---|
| **싱글비트** | 셀 하나만 고립되어 죽음 | 쉬움 |
| **로우성** | 한 행(워드라인)이 통째로 죽음. 주소에서 X가 고정된 채 Y만 바뀐다 | 여분 행 1개 |
| **칼럼성** | 한 열(비트라인)이 통째로 죽음. Y가 고정 | 여분 열 1개 |
| **블락성** | 좁은 구역이 덩어리로 죽음 | **어려움** — 행·열을 다 써도 안 덮인다 |
| **크로스** | 행과 열이 동시에. 십자 모양 | 행·열 각 1개 |
| **워드라인** | 한 행 전체 셀의 문을 여닫는 배선 |  |
| **비트라인** | 셀에 저장된 값을 읽어 나르는 배선 |  |

### 웨이퍼 맵 패턴 (WM-811K 라벨)

| 영어 | 한글 | 뜻 |
|---|---|---|
| none | 패턴 없음 | 불량이 없다는 뜻이 **아니다.** 산발 불량은 있으나 뚜렷한 공간 패턴이 없는 상태 |
| Center | 중심부 밀집 | 웨이퍼 중심 쪽에 불량이 몰림 |
| Donut | 도넛(고리형) | 중심과 가장자리 사이에 고리 모양 |
| Edge-Loc | 가장자리 국부 | 가장자리 일부 구간 |
| Edge-Ring | 가장자리 링 | 가장자리를 따라 링 전체 |
| Loc | 국부 밀집 | 어딘가 한 곳에 뭉침 |
| Random | 산발 | 전면에 흩어짐 |
| Scratch | 긁힘(선상) | 가늘고 긴 선을 따라 늘어섬 |
| Near-full | 거의 전면 | 웨이퍼 대부분이 불량 |

### 분석 기법

| 용어 | 뜻 |
|---|---|
| **Grad-CAM** | 모델이 **어디를 보고** 그렇게 판단했는지 열지도로 표시. 붉은 영역이 판단에 크게 기여한 자리 |
| **세그멘테이션** | 이미지에서 결함이 차지한 **영역을 픽셀 단위로** 골라내는 것 |
| **길이 대 폭 비(elongation)** | 결함이 얼마나 길쭉한지. 3 미만이면 둥근 덩어리, 30 이상이면 가늘고 긴 선 |
| **민감도 분석** | 가정을 바꿔가며 결론이 얼마나 흔들리는지 보는 것. 흔들리면 그것도 결과다 |

## 데이터 계층 — 혼동하기 쉬운 부분

| 계층 | 단위 | 데이터 |
|---|---|---|
| 웨이퍼 맵 | 다이 1개 = 점 1개 | WM-811K **실데이터** |
| Fail Address | 다이 **내부** 셀 주소 | **합성** (공개 데이터 없음) |
| SEM 이미지 | 결함 1개 확대 | Carinthia-S **실데이터** |

웨이퍼 맵의 빨간 점 하나가 "이 칩은 불합격"이고, Fail Address는 **그 칩 안쪽**
주소라 한 단계 더 아래다.
