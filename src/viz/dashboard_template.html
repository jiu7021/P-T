웨이퍼 맵의 다이 합불과 공간 분포는 WM-811K 실데이터입니다. 패턴 라벨 분류는 CNN 예측이며, 히트맵은 Grad-CAM으로 계산한 판단 근거 영역입니다. 균형 샘플링 표본이므로 여기 표시되는 불량률은 실제 라인 수율이 아닙니다.

분류 결과와 특징

제시된 항목은 후보이며 확정 판단이 아닙니다. 최종 판단은 엔지니어가 수행합니다.
SEM 이미지와 마스크는 Carinthia-S 실데이터입니다. 데이터셋이 결함 클래스 이름을 공개하지 않아 라벨은 숫자 1~6뿐입니다. 숫자에 임의로 결함 용어를 붙이지 않고, 마스크에서 측정한 형태를 근거로 원인 공정 후보를 조회합니다. Carinthia-S가 어느 공정 층인지도 공개되지 않았으므로, 후보는 "이 형태의 결함이 일반적으로 어느 공정에서 비롯되는가"이지 "이 이미지의 원인이 무엇인가"가 아닙니다.

이미지 선택

원본 · 정답 · 예측

원본 SEM은 밝기 표준편차 중앙값이 10.8(0~255)로 매우 낮아 그대로는 결함이 잘 보이지 않습니다. 대비 강조는 2~98 백분위로 선형 스트레칭한 표시용 처리이며, 모델 입력이나 측정값은 원본 그대로를 씁니다.

원인 공정 후보 (문헌 룩업 · 학습 대상 아님)

이 탭의 주소 데이터는 전부 합성입니다. 셀 단위 Fail Address 비트맵은 공개 데이터가 존재하지 않습니다. WM-811K는 다이 단위 합불만 제공하며 칩 내부 셀 주소는 없습니다. 판별은 학습 모델이 아니라 규칙 기반이며, 임계값은 전부 가정치입니다 — 아래 슬라이더로 직접 바꿔 결과가 얼마나 흔들리는지 확인하십시오. 주소 표기는 16진수입니다.

판별 결과와 근거

AI는 후보와 근거만 제시합니다. 원인 공정을 판정하지 않습니다. 판정은 엔지니어가 하고, 그 판정이 쌓이면 학습 데이터가 됩니다.

피드백 루프

SEM 이미지
  └→ 마스크에서 형태 측정            (관측 사실)
      └→ cause_map.yaml 룩업
          └→ 후보 + 근거 + 논문 출처 제시   ← AI가 하는 일은 여기까지
              └→ 엔지니어가 판정              ← 사람이 결정
                  └→ verdicts.jsonl 누적 (append-only)
                      └→ 준비도 판단
                          └→ 충분하면 학습 데이터로 내보내기

설계 원칙

  1. AI는 판정하지 않는다. 후보·근거·출처를 나열할 뿐 선택하지 않는다.
  2. append-only. 기존 기록을 수정하지 않는다. 판단이 바뀐 이력도 데이터다.
  3. 표본이 부족하면 학습을 거부한다. 적은 표본으로 그럴듯한 모델을 만드는 것이 이 프로젝트에서 가장 위험한 실패다.
  4. 후보 목록 밖 판정을 막지 않는다. 그것이 쌓이면 룩업 표를 개정할 근거가 된다.

학습 준비 기준 가정치

조건기준
엔지니어 판정 총 건수≥ 100
30건 이상 모인 공정 종류≥ 2
공정당 최소 건수≥ 30

공개된 기준이 없습니다. 클래스당 수십 건 미만이면 검증셋 분리조차 성립하지 않습니다(Module B의 class 5가 4장이라 F1이 무의미했던 것과 같은 문제). 이 값을 넘겨도 성능이 보장되지는 않습니다. 하한일 뿐입니다.

판정 입력 (CLI)

# 후보 확인 (판정하지 않음)
python src/model/feedback.py show --image <filename>

# 엔지니어 판정 기록
python src/model/feedback.py add --image <filename> \
    --process CMP --engineer <이름> \
    --confidence high --rationale "연마 방향과 일치"

# 누적 현황·학습 준비도
python src/model/feedback.py stats

대시보드는 브라우저 저장소를 쓰지 않으므로 판정 입력은 CLI로 받습니다. 이 화면은 조회 전용입니다.

이 프로젝트가 주장하는 것과 주장하지 않는 것

  • 웨이퍼 맵의 다이 합불과 공간 분포는 WM-811K 실데이터입니다.
  • SEM 결함 이미지와 세그멘테이션 마스크는 Carinthia-S 실데이터입니다.
  • Fail Address는 공개 데이터가 없어 합성했습니다. 절대값이 실제 제품과 같다고 주장하지 않습니다.
  • 원인 공정 추정은 모델이 아니라 문헌 기반 룩업이며 확정 판단은 사람이 수행합니다.
  • 따라서 주장하는 것은 모델 성능이 아니라 분석 흐름의 설계와 의사결정 근거의 가시화입니다.
